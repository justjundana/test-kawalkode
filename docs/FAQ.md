# Frequently Asked Questions (FAQ)

## What is jsonfmt?
A CLI tool for formatting and validating JSON files with robust error handling.

## How do I install jsonfmt?
See the [README](../README.md#installation) for installation instructions.

## Does jsonfmt support JSON Schema validation?
Yes, use the `--schema` flag to validate a JSON file against a schema.

## Can I format multiple files at once?
Not yet. Current version supports one file per invocation.

## Does it overwrite files?
Yes, unless you use the `--stdout` flag.

## How do I report a bug or request a feature?
Open an issue or pull request on GitHub.

## How do I run tests?
Run `go test -cover ./...` in the project root.

## Where can I get help?
Open an issue or contact the maintainer listed in the README.
