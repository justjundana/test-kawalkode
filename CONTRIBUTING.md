# Contributing to jsonfmt

Thank you for your interest in contributing!

## How to Contribute
- Fork the repository and create your branch from `main`.
- Write clear, atomic commits and descriptive PRs.
- Ensure all tests pass (`go test ./...`).
- Follow Go idioms and match existing code style.
- For bug reports, include steps to reproduce.
- For features, explain motivation and use case.

## Code Style
- Use `gofmt` before committing.
- Write tests for new features or bugfixes.
- Document exported functions and types.

## Pull Requests
- Reference related issues if applicable.
- Keep PRs focused and minimal.
- Be responsive to review feedback.

## Community
- Be respectful and constructive.
- See [CODE OF CONDUCT](CODE_OF_CONDUCT.md) if present.

---

Thank you for helping improve jsonfmt!
